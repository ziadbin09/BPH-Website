# Buraaq Psychological Hub Website

Static, responsive website for Buraaq Psychological Hub (BPH).

## Pages / sections
- Home
- About Us
- Mission & Vision
- Initiatives
- Contact / Instagram

## Logo
The website expects the official Instagram profile logo at:
`assets/bph-logo.png`

The Instagram page could not be programmatically fetched during this build because Instagram throttled the request. Place the exact profile-picture/logo image from the BPH Instagram profile into `assets/bph-logo.png`; the header will then use it automatically.

## Run locally
Open `index.html` in a browser, or use any static server.

## Free deployment
Upload the folder to GitHub Pages, Netlify, or Vercel as a static site.
